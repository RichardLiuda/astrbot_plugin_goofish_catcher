# 技能：采购决策卡片

**工具**：`buyagent_purchase_decision`
**场景**：用户想买某个东西、比价、蹲好价，或需求描述模糊（颜色/预算/成色），需要一个"买什么、在哪买、什么价合理"的直接结论。

与 `goofish_search_live` 的区别：
- `goofish_search_live` → 只搜闲鱼，返回原始列表，用户自己判断
- `buyagent_purchase_decision` → **多平台并发 + 自动降级 + 聚合排序**，直接给决策结论

## 工具参数

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `requirement` | string | 必填 | 采购需求原文，如 "红色 RTX 5090 预算1万5" |
| `top_k` | int | 5 | 最多推荐条数，上限 10 |

## 工具行为（数据流）

```
用户自然语言需求
  → ① 意图引擎拆解：关键词/属性（颜色等）/预算/成色 + 生成降级阶梯 L0-L3
      （LLM 解析，失败回退启发式：整句当关键词、正则抓预算）
  → ② 多平台并发搜索：asyncio.gather 打所有启用的平台
      （单平台 20s 超时、异常隔离——一个平台挂了卡片照常出）
  → ③ 精确匹配为空 → 自动按阶梯降级重搜，记录命中层级
      L0 精确匹配（红色 RTX 5090）
      L1 去掉颜色限制（RTX 5090）💡提示"可考虑黑色+RGB调红/改色膜"
      L2 妥协成色（二手也可）
      L3 替代方案建议
  → ④ 聚合：平台内去重 → 同店聚类（同店同款 ×N）→ 风险标签
      （闲鱼=二手/无发票；淘宝=品牌旗舰店 vs C店注意验货）
  → ⑤ 排序：LLM 综合"价格/市场均价分位/风险/需求匹配度"（宁缺毋滥，
      启发式兜底）；**能识别淘宝 SKU 低价引流**（"价格异常/混合型号风险"）
  → ⑥ 渲染 Markdown 决策卡片并发送到对话（aiocqhttp 合并转发，其他纯文本）
  → ⑦ 返回给 LLM 的只是摘要（命中层级、各平台条数、降级说明）
```

## 决策卡片格式

```
🛒 采购决策：红色 RTX 5090 预算1万5

🔍 关键词：RTX 5090 显卡｜🎨 颜色=红色｜💰 预算：≤15000 元

⚠️ 精确匹配（L0 红色 RTX 5090）无结果，已降级到 L1：放宽颜色限制
💡 可考虑黑色+RGB调红/改色膜

【淘宝】3 条 · 参考价 16566 元（市场均价）
1. [88] 华硕ROG RTX5090 夜神 32G 全新未拆封
   ¥15788.00（低于参考价 26%）｜店铺=ROG旗舰店｜销量 300+
   ✅ 品牌/官方店铺
   🔗 https://detail.tmall.com/item.htm?id=...

【闲鱼】另有 28 条结果，综合评分未进本次推荐

🛡️ 风险与建议：……
⚠️ 失败平台：京东（超时）——仅在有平台失败时出现
```

## 典型对话

**用户**：帮我看看红色 RTX 5090，预算 1 万 5
**LLM 动作**：`buyagent_purchase_decision(requirement="红色 RTX 5090 预算1万5")`
**LLM 回复**：已生成采购决策卡片（上方）。没有红色现货，已自动放宽颜色限制并给出改色建议；淘宝 ROG 旗舰店 ¥15788 低于市场价 26%，建议优先考虑。

**用户**：蹲一个二手徕卡 M11，1 万 8 以内
**LLM 动作**：`buyagent_purchase_decision(requirement="二手徕卡M11 1万8以内")`

## 注意事项

- **结果好坏取决于启用平台数**：只有闲鱼可用时卡片只有闲鱼节；淘宝未启用（`taobao_enabled`）或会话失效时，失败平台节会注明
- 模糊需求（"红色的"）放心交给降级路径，**精确匹配不到绝不返回空**
- 淘宝条目价格是**列表价**（SKU 区间最低），需要真实档位价时用 `goofish_analyze_item_detail` 查单个淘宝商品（有 SKU 全档价目表）
- 引用卡片回复序号想收藏：**淘宝商品会提示"该平台收藏暂不支持"并跳过**，闲鱼正常收藏
- 用户追问"未进推荐的都有啥"时**可直接回答**：工具返回值里带"未进推荐候选简表"（平台/标题/价格，封顶 12 条），无需重新搜索；决策结果是一次性的（不写 items 表），`goofish_list_items` 查不到这些候选
- 无 LLM 环境（`llm_enabled=false`）时走启发式解析与排序，决策质量下降但流程不变
