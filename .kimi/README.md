# .kimi — 项目知识库（Kimi Code 专用）

作用：等价于原作者的 `.claude/skills/`，沉淀本项目的开发注意事项与操作指南。
**新会话开始时先读本目录，不要重新通读项目。**

## 文件地图

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| [architecture.md](architecture.md) | 模块地图、核心数据流、DB schema、配置体系 | 改任何代码前 |
| [gotchas.md](gotchas.md) | 实战坑、测试基线、发版流程、实验结论 | 动手前必看 |
| [roadmap.md](roadmap.md) | 多平台改造方案、四个已定决策、阶段进度 | 规划/继续改造前 |

用户/开发者向文档：`skills/`（仓库根目录）——原项目工具技能说明 + 多平台新增：
`purchase.md`（决策卡片工具）、`platforms.md`（多平台机制/淘宝数据真相），
README.md 决策树已含全部 18 个工具。

## 维护规则（遵循 skills/neat 洁癖原则）

- 同一事实只留一个权威版本；代码行为变了就同步改这里，不追加平行版本
- 这里只放「下次会话不看到就会犯错」的知识：边界、命令、数据流、已验证结论
- 历史过程进 CHANGELOG.md，机制细节进本目录，流水账不进任何地方
- 未验证的结论标 `pending`，不许写成事实
